## 2. 動画手法の4大骨子（技術的解剖）

| # | 柱 | 裁量理論 | 日足スイング・システムへの翻訳仕様 |
| :--- | :--- | :--- | :--- |
| **①** | **どこで戦うのか** | 上位足の水平レジサポ・節目まで手を出さず待つ | 週足・日足の過去高値/安値、主要移動平均線（75MA/200MA）付近に位置する銘柄のみをスクリーニング |
| **②** | **何をもって間違えたと認めるのか** | エントリー前に損切り（SL）位置とリスクリワード（R/R比）を確定 | 直近スイング安値または支持線を「シナリオ否定ライン」として自動特定し、R/R比（1:2以上等）を算出・提示 |
| **③** | **いつ引き金を引くのか** | 下位足のトレンドラインブレイク・ロールリバーサル | 日足確定での前日高値突破、または支持線反発陽線（ロールリバーサル確定）をシグナル化 |
| **④** | **最後に確認するべきたった1つの穴** | 教科書通りブレイクに飛び乗る素人を狩る大口の罠（ダマシ・ストップ狩り）の回避 | 出来高急増にもかかわらず上ヒゲ陰線となった銘柄（高値掴み・ブレイク失敗）を自動排除 |

## 3. 現行システム（Stock-analysis-system-main）との親和性分析

### ◎ 親和性が極めて高い領域（即戦力）
1. **損切りライン（SL）とリスクリワード比（R/R比）の自動算出**:
   - 現行ツールは「買いシグナル」の提示に留まっており、投資判断に必要な「撤退基準」が欠落している。
   - スイング安値をシナリオ否定ラインとして算出し、「推奨損切り価格・想定利確目標・R/R比」をメール・ダッシュボードに表示することで実用性が飛躍的に向上する。
2. **ダマシ・高値掴み防止フィルター（4つ目の穴）**:
   - 現行のA群条件（出来高急増＋20日高値更新）が抱える「高値掴み・上ヒゲ陰線トラップ」を排除し、勝率を底上げする。

### ▲ ギャップと課題（対応方針）
1. **時間軸のギャップ（日足バッチ vs 分足のリアルタイム監視）**:
   - 動画は分足〜時間足のザラバ監視を前提としているが、本システムはGitHub Actionsによる日足EOD（1日1回）バッチ。
   - **対応**: 日中リアルタイムではなく、日足スイングトレード（夜間分析・翌朝寄り付きエントリー）に特化したロジックとして設計する。
2. **裁量トレンドライン描画の難しさ**:
   - 斜めのトレンドラインは機械的描画で誤差が出やすいため、**客観的な水平レジサポ線・直近高値安値・価格帯別節目**に置き換える。

## 4. 統合ロードマップ

1. **Phase 1（リスク管理機能の追加）**:
   - 各シグナル銘柄に対する損切り価格・目標価格・リスクリワード比の自動計算とレポート表示。
2. **Phase 2（ダマシ排除フィルター）**:
   - 上ヒゲ率判定、出来高天井パターンの除外ロジック実装。
3. **Phase 3（IPPO AIプロンプトの進化）**:
   - Gemini（IPPO）に上記「レジサポ・損切りライン・リスクリワード比」をインプットし、プロトレーダー視点での論理的なエントリーシナリオを自動執筆させる。
